# Auditoria de mymusicdl — 2026-09-11

Auditoria del codi local del backend, frontend, descàrregues, actualitzador, metadades,
bots i configuració de construcció. Els canvis de permisos preexistents s'han conservat.

## Verificació executada

- Base inicial: 35 proves existents aprovades; compilació frontend correcta.
- Resultat: **78 proves aprovades**, incloent regressions noves a `tests/test_audit.py` i `tests/test_api.py`.
- `ruff check backend`, `black --check backend`, importació de `create_app()` i `git diff --check`: correctes.
- `npm run build`: correcte; `npm audit`: **0 vulnerabilitats**.
- `pip check`: correcte. `pip-audit` sobre les dependències instal·lades a l'entorn temporal: **0 vulnerabilitats conegudes**, després d'actualitzar el pip d'aquest entorn. Això no verifica les versions d'un desplegament existent.
- Arrencada i tancament reals del lifespan amb SQLite temporal: respostes 200 a health, settings, jobs, library/items, bots i tools; clients HTTP tancats i workers aturats.
- Flux de descàrrega amb el proveïdor yt-dlp i un executable de prova: generació d'un WAV real dins del volum temporal, registre a SQLite i petició de rescan al doble de Navidrome.
- Chromium amb API simulada: cinc pantalles principals, canvi d'àlbum després d'un error, selector de qualitat per proveïdor, renderització mòbil i respostes de previsualització fora d'ordre. Sense excepcions JavaScript.

## Límits i punts pendents

- No s'ha construït la imatge Docker: l'usuari d'aquesta sessió no té accés al socket Docker. Cal executar `docker build -t mymusicdl:test .` en un entorn amb accés abans de publicar la imatge.
- No s'han fet descàrregues reals de serveis externs, escaneigs d'un Navidrome real ni enviaments de missatges. La integració de descàrrega, els bots i les crides externes s'han comprovat amb dobles de prova.
- Els adaptadors de pagament streamrip/tiddl ja contenien funcionalitat incompleta: especialment configuració efectiva de credencials per al CLI i resolució de catàleg natiu. Aquesta auditoria no els converteix en integracions completes. Continuen requerint implementació i validació amb comptes vàlids; no s'ha canviat la regla d'activació per presència de credencials.
- No s'han modificat credencials, dades de música, desplegaments, commits ni remots.
